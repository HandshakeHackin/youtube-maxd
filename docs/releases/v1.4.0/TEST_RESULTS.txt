YouTube Max’d v1.4.0 — software validation
Date: 2026-10-19. Firmware 11.00 / ShadowMount+ is the intended target, not a
claim of a performed hardware test. No PS5 is attached to the build environment.

Recorded checks:
- Real loopback HTTP remote listener under ASan/UBSan: passed. Covers local-only
  binding policy, authentication, origin/duplicate-header/framing rejection,
  one-use QR, five-minute invite/two-hour session expiry, restart revocation,
  stale selection refusal, command sequence/deduplication, literal search,
  queue command validation and protected report download.
- Shipping C++ remote/player adapter under ASan/UBSan: passed. Pause/resume,
  stale selection, paused seeking/clamping, live/keyboard/voice/casting/startup
  refusal, literal search text, background return and queue routing.
- Diagnostics under ASan/UBSan: passed. Closed 25-field allowlist, enum codecs,
  numeric bounds/NaN/infinity handling, exact app version, atomic private-file
  export/overwrite, clear and interrupted-write recovery.
- Generated phone page consistency and Node tests: passed. Supported YouTube
  IDs/links, hostile URL rejection, text-only DOM rendering, URL secret removal,
  sessionStorage scope, credential omission, selection guard and Blob download.
- Native lightbar bridge and fork title/storage/update isolation: passed.
- Release identity/version consistency and generated About changelog: passed.
- Afterglow regression: 25 fixture boards x 4 looks, 1,132 checks, zero failed.
  The refreshed report-field fixtures are also checked in the final phone UI run.
- Generated background playback lifecycle regression: passed. Ownership,
  hidden-player update, fenced discard, EOF behavior, return and modal/voice guards.

- Actual generated provider ASan/UBSan integration: passed. Remote settings/QR,
  idempotent queue add/remove/play-next, 25-field TV report review, capture/clear,
  profile isolation and shutdown. Existing support, transcript/bookmark/session,
  family/PIN/channel/time and party HTTP/queue integration checks also pass.
- Embedded service plain host fixtures: self-test 21; HTTP 186; accounts 232;
  subscription import 51; existing phone receiver 302. All pass, zero failed.
- Final phone UI fixtures: 7 boards x 4 looks, 400 checks, zero failed, including

- Final native PS5 build: passed, 314 objects. Signed plaintext FSELF integrity
  is valid; executable SHA-256 is recorded in release-plan.json/native-validation.json.
- App ZIP: 99,530,570 bytes, 305 entries. CRCs, PPSA99991 / 01.004.000 identity,
  retained model/helpers/icon and 0777 entry permissions verified.
- Catalog format: 108 valid records, zero errors/warnings/notices.
- Catalog static scan: passed, zero errors, six warnings and one notice.

Final archive/source checksums and matching-source manifest counts are recorded
in native-validation.json and SHA256SUMS after release assembly.
