# ProsperoTube

A planned native YouTube client for PlayStation 5 homebrew, inspired by
[SmartTube](https://github.com/yuliskov/SmartTube),
[ProsperoTV](https://github.com/blackbearreloaded/ProsperoTV), and
[EVO Player](https://github.com/sainsaji/EVO-PLAYER-PS5).

**Status: feasibility and implementation planning.** No application or console
playback prototype has been implemented in this repository yet.

See [the implementation plan](IMPLEMENTATION_PLAN.md) for the proposed architecture,
source references, milestones, validation gates, difficult areas, and open questions.

The intended destination is a native PS5 application. A companion service is an
optional prototype/fallback approach whose suitability remains to be decided.
